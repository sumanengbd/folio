# Folio — PDF Tools

Local web app for everyday PDF work. Nothing is uploaded. Files stay on this device.

## Tools

1. **Images → PDF** — drop photos or scans, arrange pages, download a PDF
2. **PDF → Images** — page range (`1–3, 5, 8`), then PNG / JPG / WebP
3. **Merge PDFs** — drop several files, drag the strip to order, one PDF out
4. **Split PDF** — pick pages or a range, save as one PDF or a ZIP of pages
5. **Compress** — shrink a PDF or images (smaller / balanced / sharper)
6. **Text tools** — uppercase, lowercase, sentence case, and more; copy, download, or print
7. **ID / Bank Card** — NID, bank, passport photo, driving licence; bleed and crop marks; batch several people into one PDF

## Install as an app

In Chrome (or Edge), click **Install app** in the left menu, or use the install icon in the address bar. After that Folio opens in its own window.

On iPhone: tap **Install app**, then Share → Add to Home Screen.

## Images → PDF

- Add images from the strip or drop them on the desk
- Page size, orientation, fit, and margin are in the right sidebar
- In landscape, **Rotate** in the sidebar can turn a portrait photo to match the page
- The **Portrait / Landscape** chip on each page (or **R**) changes that page only
- Download builds the PDF only when you click **Download PDF**
- **Print** opens the printer dialog without saving a file first

## PDF → Images

- **Each page as an image** (default) or extract embedded images
- **Pages** — leave blank for all, or type `1–3, 5, 8`
- **Image format** — PNG, JPG, or WebP
- **This image** / **All images** / **Download ZIP** / **Print**
- The **Portrait / Landscape** chip on a page changes that image; download and print match

## Merge / Split / Compress

- Merge: add PDFs, drag thumbs to set order, download or print one file
- Split: open a PDF, type a range or click thumbs, download PDF, print, or each-page ZIP
- Each middle page can switch **Portrait / Landscape**; the saved PDF follows that page
- Compress: open a PDF or photos, pick quality, download or print a smaller file

## Text tools

- Type or paste in the middle, or drop a `.txt` file
- **UPPERCASE**, **lowercase**, **Sentence case**, **Title Case**, invert, alternating, trim spaces, one paragraph, reverse
- If you select text first, the change applies only to the selection
- Copy, download `.txt`, or print

## ID / Bank Card

- Card types: NID, bank card, passport photo (35 × 45 mm), driving licence
- Bleed 0 / 2 / 3 mm and crop marks for print shops
- **Add person** for a batch PDF (one page per person)
- Front on top, back below (passport is front only)
- Drag to crop, scroll to zoom, rotate to straighten a phone photo
- Download PDF or PNG at true card size, or **Print** without saving first

Settings (tool, page size, rail) are remembered in the browser. ID card photos are stored in IndexedDB on this device only.
